props 는 반드시 부모에서 자녀에게만 데이터를 줄수 있음!!
props의 자료형태는 반드시 객체의 타입임
props로 데이터를 받아올 때, 구조분해 할당을 통해 바로 변수값으로 찾아올 수있음 (*이때, 반드시 객체 내 key 네이밍과 동일한 변수명을 설정)
심지어 props는 컴포넌트도 전송가능 (*단, 컴포넌트를 전송할 때에는 key값이 children으로 자동 설정됨)



* 웹 브라이주 상에서 동적인 변화가 발생되었을 때, 감지하고, 업데이트를 시켜줄 수 있어야 => 데이터를 가공.편집.전송 가능

1) 사용자가 입력한 값
2) 사용자가 값을 입력했다는 사실을 인지할 수 있어야한다
=> 사용자로 인하여 상태가 업데이트가 되었다
3) 사용자가 입력한 값을 가져온다

*useState 훅 함수 실행 => 배열값으 반환 !! => 초기값 / 초기값을 변경시킬 수 있는 함수
