<Link />  VS useNavigate( )

<Link /> => 사용자가 직접 어떤 행위를 해서 특정 페이지로 이동시켜 주고자 할 때
( to 속성을 활용해서 이동시키고자 하는 경로를 설정 )

useNavigate( ) => 사용자의 의도와 관계없이 개발자 혹은 마케터 혹은 기획자가 사용자를 어떤 페이지를 이끌고자 할 때
( 버튼 클릭후 이벤트 결과값으로 자동 이동 될때 많이 씀 ) => React Hook (함수)

outlet : 특정 컴포넌트 페이지에 도착을 했을 때, 이에 맞는 자식 컴포넌트 페이지가 존재하면, 해당 컴포넌트 페이지를 보여주게 하는 역할
=> 페이지 라우팅 기능만 하는 것이 아니라, 데이터를 전달해주는 역할도 함!



API : 아무 제약조건 없이 가져다가 사용할 수 있다면!!
> CORS : 통신 프로토콜 규정 위반!!
> 데이터를 전송 (*Server) : https 통신프로토콜 준수
> 데이터를 수신 (*Client) : http 통신 프로토콜 비준수
