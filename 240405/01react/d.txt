Page Routing 기능 구현 !!!
=> 메인이 되는 컴포넌트 에서 일종의 스위치를 설치!!

1.index.js 
- 메인 컴포넌트에 페이지 라우팅 기능을 구현하고자 하는 컴포넌트를 찾아서 <BrowserRouter/> 설정
2. App.js
- <Routes/> & <Route> => 페이지 분기 작업!
-<Route / > : path & element
- path : 경로 => 상단 주소창의 경로 정의
- element: 보여줄 컴포넌트 소스 정의

<예>
https://www.musinsa.com/app/goods/1149329?loc=goods_rank
https://www.musinsa.com/app/goods/3771149?loc=goods_rank

Page Routing 을 설정할 때, URL Parameter 정의할 수 있음!!!
기본적인 page url 뒤에 "/" 특정정보라는 것을 인식할 수 있는 일종의 변수 값!!!

URL Parameter 값 뒤에 "?" 와 함께 입력되어 지는 값을 Query String 이라고 부름!
=> Query: 질의하다 질문하다 
=> String: 문자열
