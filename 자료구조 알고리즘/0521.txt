*시간 복잡도
- 프로그래밍 영역에서는 시간이 가장 오래걸릴 것으로 판단돠는 그 구간을 발췌해서 시간복잡도를 계산

- 자바스크립트를 잘한다는 말은 => 배열과 반복문을 내가 자유롭게 가지고 놀 수 있으면 됨
- 모든 프로그래밍 언어는 다 저마다의 반복문이있음.
- 사람이 일일히 비효율적으로 작업해야하는 단순 반복적인 행위를 ㅇ컴퓨터에 맡김으로인해서 프로그래밍 효율성 극대화!

- 어떠한 문제를 해결해나가는데 걸리는 소요시간
- 두사람이 동시에 반복문

(*for/ for of / while)
*어떻게 계산? (시간복잡도)

arr = [1, 3, 5, 7];

//=> 미션, 주어진 배열에서 5를 찾으세요!
// 1) 한번에 직접 찾는방법
// 2) 반복문 1~7까지를 순회하면서 찾는방법
// 3) 1, 3, 7, ~5 (*배열의 길이수 만큼 시간이걸리는 방법)

=> 가장 시간이 많이 걸리는 상황을 전제하에 시간복잡도를 계산!

* 시간 복잡도의 단위!!
- 빅오메가 : 최선의 경우, 한 번에 찾을때를 의미
- 빅오 : 최악의 경우, 배열의 길이만큼 시간이 걸리는 것을 의미
- 빅세타 : 평균의 경우, 배열의 길이 중간 만큼 시간이 걸리는 것을 의미
